04 / HOW I APPROACH PROBLEMS

Find the cause.
Fix it with a plan.

While building and updating my portfolio, I learned to solve issues by checking one thing at a time, testing changes, and confirming the result instead of changing many lines of code at once.

01 My website design did not change after editing CSS ＋

Problem: The page still showed the old colors even after I changed the stylesheet.

What I would check: Confirm that the HTML links to the correct CSS filename, make sure both files are in the expected folder, commit the latest changes, and hard-refresh the browser.

Solution and lesson: Check the file connection first before rewriting the design. Small checks can reveal whether the issue is the code, file path, or cached page.

02 A project picture made the card layout uneven ＋

Problem: A large image pushed the project details out of alignment.

What I would check: Inspect the image element and its container, then apply a consistent width, a suitable fixed or aspect-ratio-based height, and object-fit: cover or contain depending on the image.

Solution and lesson: Control the image through CSS rather than stretching the image itself. Test the card on desktop and mobile to make sure the text remains readable.

03 The resume photo looked tilted and out of place ＋

Problem: The photo frame was rotated, so the resume looked less formal.

What I would check: Find the CSS rule for the resume photo frame and remove the rotation transform. Then use a consistent rectangular frame, align it with the name and contact details, and check the print layout.

Solution and lesson: Keep professional documents simple and aligned so the reader can scan important information quickly.

04 A section was missing from the navigation menu ＋

Problem: Some portfolio sections could only be found by scrolling through the page.

What I would check: List every section ID, compare it with each navigation link, and make sure each link uses the exact matching ID.

Solution and lesson: Use clear, consistent section IDs and test every navigation link after publishing. A menu should help visitors reach all important sections easily.

05 Text was difficult to read against the background ＋

Problem: Some text used a light color on a light background, making the words hard to read.

What I would check: Inspect the text and background colors for the affected section, then use a dark text color on light surfaces or a light text color on dark surfaces. Also check links, captions, and small labels.

Solution and lesson: Readability comes first. Check the page at different screen sizes and avoid relying on color alone to communicate important information.
